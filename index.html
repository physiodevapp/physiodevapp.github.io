Qué he construido

PhysiQ

Suite clínica · en uso en consulta

Aplicación web instalable que reúne las herramientas de valoración funcional que uso a diario: cinemática articular a partir de vídeo, medición de rango con el acelerómetro del móvil, dinamometría conectada por Bluetooth, equilibrio, salto, cuestionarios de resultado y una referencia de tests ortopédicos.

Incluye un copiloto que transcribe la sesión y devuelve hipótesis apoyadas en una base de conocimiento propia, citando siempre la fuente. Se puede probar en modo demostración, sin instalar nada.

JavaScript · PWA · TensorFlow.js · OpenCV.js · Web Bluetooth · Cloudflare Workers · Supabase pgvector · Deepgram · Next.js y TypeScript en el módulo de cinemática
